### 🐝 ZiggleBee

Developed ZiggleBee, an accessibility-focused platform for disabled users with Admin and Owner portals. Implemented subscription-based plans with Stripe integration for automated payments and feature access control. Built a template builder system to create accessible content. The platform enables users to manage subscriptions, features, and settings with ease while ensuring an inclusive experience.

### 🏘️ Adfy

A real estate management platform designed for agents, customers, and dealers to streamline property transactions and document management. The system securely stores agreements and other legal documents, while AI-powered analysis helps identify missing information, compliance issues, and potential legal risks. It also includes a configurable workflow builder that automates approval processes, task management, and document review throughout the transaction lifecycle.

> 🔒 Private repository (Esquall org)

| Layer | Technology |
|---|---|
| Frontend | React.js, Next.js, TypeScript |
| Backend | Node.js, Express.js |
| AI | AI-Powered Document Analysis |
| Cloud | Microsoft Azure / AWS |
